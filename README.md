# CrystaCode Full-Stack AI Bootcamp
This bootcamp is designed to equip developers with the skills needed to build full-stack applications powered by AI. Participants will learn how to leverage AI tools and frameworks to enhance their development process, from backend to frontend.

This bootcamp is ideal for developers who have passed the CS Internship C# program and are looking to expand their skill set into full-stack development with a focus on AI integration.

## Curriculum
The curriculum covers a range of topics, including:
- Introduction to AI and Machine Learning
- Learning with AI
- Development using AI (GitHub Copilot, Claude, Codex, etc.)
- C# and .NET
  - [ASP.NET Core](/design/flows/flow-dotnet-aspnetcore.md)
  - [Blazor](/design/flows/flow-dotnet-blazor.md)
  - [AI, MEAI, MAF](/design/flows/flow-dotnet-ai.md)
- [Frontend Development (HTML, CSS, TypeScript)](/design/flows/flow-frontend.md)
