## Overview
In this flow, we will build practical AI literacy for learning, research, content creation, and software development. Each lesson combines a short explanation or demonstration with an immediate hands-on activity. You will learn what modern generative systems can do, where they fail, how to give them useful instructions and context, and how to keep human judgment in control.

Following steps help you to master these topics:
  - Generative AI and Large Language Model Fundamentals
  - Responsible Use, Privacy, and Output Verification
  - Learning and Research with AI
  - Prompt, Context, and Loop Engineering
  - Image, Presentation, and Social Content Creation
  - AI-Assisted Development with GitHub Copilot

## Steps
The checklist is a modular catalog of topics and practical outcomes. It does not prescribe course order; course designers can select, combine, and arrange the items for each audience:

1. [ ] Explain generative AI, common model types, major capabilities, limitations, and the continuing role of human expertise. Identify five useful applications and three decisions that should remain human-controlled ([Generative AI in a Nutshell](https://www.youtube.com/watch?v=2IK3DFHRFfw))
2. [ ] Explain how large language models work, including training data, tokens, next-token prediction, parameters, inference, fine-tuning, and output limitations. Represent the explanation with a one-page diagram ([Large Language Models](https://www.youtube.com/watch?v=osKyvYJ3PRM), [LLM Deep Dive](https://www.youtube.com/watch?v=7xTGNNLPyMI))
3. [ ] Evaluate AI limitations and responsible-use concerns through practical tests involving factual recall, reasoning, ambiguous instructions, sensitive data, bias, copyright, disclosure, and human accountability ([Large Language Models](https://www.youtube.com/watch?v=osKyvYJ3PRM), [LLM Deep Dive](https://www.youtube.com/watch?v=7xTGNNLPyMI))
4. [ ] Compare integrated browser assistants using the same article or PDF in Edge and Chrome. Test summarization, explanation, page-based questions, and quizzes; inspect shared browser data and verify answers against the source ([Copilot in Microsoft Edge](https://support.microsoft.com/en-us/microsoft-copilot/getting-started-with-copilot-in-microsoft-edge), [Gemini in Chrome](https://support.google.com/chrome/answer/16283624?hl=en))
5. [ ] Use Gemini for practical learning and productivity tasks involving text, files, images, model selection, temporary conversations, Canvas, Guided Learning, and Deep Research. Record which feature fits each task and why ([Gemini Practical Course](https://www.youtube.com/watch?v=-_FizlRlfYs))
6. [ ] Use ChatGPT Study Mode to conduct a guided learning session with prior-knowledge questions, explanations, learner attempts, feedback, and a mastery check. Compare guided study with ordinary direct-answer chat ([Introducing Study Mode](https://www.youtube.com/watch?v=XDYilxy1dn8), [Study Mode Guide](https://help.openai.com/en/articles/11780217-study-mode))
7. [ ] Build a source-grounded Gemini Notebook containing trustworthy files, websites, and conversations. Organize a project, configure notebook memory and custom instructions, use cited chat, and verify important claims against their sources ([Gemini Notebook Integration](https://www.youtube.com/watch?v=Y-LTxr1bv9M), [Product Guide](https://support.google.com/gemininotebook/answer/16164461?hl=en))
8. [ ] Conduct the same focused research question with two deep-research tools. Review the research plans, open cited sources, and compare coverage, evidence quality, missing viewpoints, and unsupported conclusions ([Gemini Practical Course](https://www.youtube.com/watch?v=-_FizlRlfYs), [ChatGPT Deep Research](https://www.youtube.com/watch?v=YkCDVn3_wiw))
9. [ ] Apply prompt-engineering principles to everyday tasks: define the goal, audience, context, constraints, examples, and output format; test prompts against several inputs and improve them using a quality rubric ([Prompt Engineering Guide](https://www.youtube.com/watch?v=uDIW34h8cmM))
10. [ ] Build a small prompt-based application that summarizes, infers, transforms, or expands text. Inspect edge cases, require structured outputs, iterate on failures, and include human review before using the result ([Prompt Engineering for Developers](https://learn.deeplearning.ai/courses/chatgpt-prompt-eng/lesson/dfbds/introduction))
11. [ ] Apply context engineering by creating a reusable context pack containing goals, source material, examples, constraints, vocabulary, project conventions, and a definition of done. Compare results with and without the context pack ([Context Engineering with Copilot](https://www.youtube.com/watch?v=0jEzUhU8bLc))
12. [ ] Design a bounded AI loop with a goal, plan, action, observation, evaluation rubric, revision process, iteration limit, stop conditions, and human approval points. Test the loop with a writer, critic, and reviser workflow ([Agent-First Development](https://www.youtube.com/watch?v=uu4sf8z9n8c))
13. [ ] Create a source-based content brief and transform it into an article, email, and social post for different audiences. Verify facts, preserve the intended voice, remove unsupported claims, and perform a human editorial review ([Gemini Practical Course](https://www.youtube.com/watch?v=-_FizlRlfYs))
14. [ ] Generate and refine an image for a real communication goal. Evaluate composition, details, style, text accuracy, audience fit, rights, disclosure requirements, and consistency across variations ([Image Creation Examples](https://www.youtube.com/watch?v=EUEsvyEMRzY))
15. [ ] Create a presentation from verified source material. Define the audience and objective, prepare a story outline, generate and simplify the slides, add accessible visuals and speaker notes, fact-check the content, and rehearse the result ([Gemini Notebook Integration](https://www.youtube.com/watch?v=Y-LTxr1bv9M), [Presentations with Microsoft 365 Copilot](https://www.youtube.com/watch?v=ioV4kREDrso))
16. [ ] Use GitHub Copilot in VS Code for code explanation, completion, design exploration, debugging, refactoring, tests, documentation, and review. Inspect suggested changes and run relevant checks before accepting them ([Getting Started with GitHub Copilot](https://www.youtube.com/watch?v=n0NlxUyA7FI))
17. [ ] Build a small feature with agent mode in VS Code. Provide a bounded issue and definition of done, review the proposed plan and commands, inspect each change, run tests, and evaluate the final diff ([Agent-First Development](https://www.youtube.com/watch?v=uu4sf8z9n8c), [Build an App with Agent Mode](https://www.youtube.com/watch?v=hmfldW7dmgw))
18. [ ] Add persistent repository context containing architecture, conventions, build and test commands, safety rules, and completion criteria. Compare Copilot's work with and without these instructions ([Context Engineering with Copilot](https://www.youtube.com/watch?v=0jEzUhU8bLc))
19. [ ] Use GitHub Copilot in Visual Studio for codebase questions, editing, refactoring, test generation, diff review, and agent tasks. Compare the experience with VS Code for a C# or .NET project ([Agent Mode in Visual Studio](https://www.youtube.com/watch?v=7_duh0HoT9o))
20. [ ] Explore how AI changes application development, including intelligent product features, smaller models, multimodal interfaces, tool use, and agentic systems. Create an AI opportunity map for an existing application with evaluation criteria, risks, and non-AI fallbacks ([AI for Application Developers](https://www.youtube.com/watch?v=awztkr8n0AA))
21. [ ] Produce an integrated portfolio project containing a source-grounded research brief, an educational artifact, an image or presentation, and a small AI-assisted application. Include the prompts, context, sources, checks, corrections, and human-controlled decisions
