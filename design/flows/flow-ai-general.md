## Overview
In this flow, we will build practical AI literacy for learning, research, content creation, and software development. Each lesson combines a short explanation or demonstration with an immediate hands-on activity. You will learn what modern generative systems can do, where they fail, how to give them useful instructions and context, and how to keep human judgment in control.

Following steps help you to master these topics:
  - Generative AI and Large Language Model Fundamentals
  - Hallucinations, Output Verification, and Human Accountability
  - Learning and Research with AI
  - Prompt, Context, and Loop Engineering
  - Image, Presentation, and Social Content Creation
  - AI-Assisted Development with GitHub Copilot

## Steps
The checklist is a modular catalog of topics and practical outcomes. It does not prescribe course order; course designers can select, combine, and arrange the items for each audience:

1. [ ] Explain generative AI, common model types, major capabilities, limitations, and the continuing role of human expertise. Identify five useful applications and three decisions that should remain human-controlled ([Generative AI in a Nutshell](https://www.youtube.com/watch?v=2IK3DFHRFfw))
2. [ ] Explain in plain language how a large language model generates a response through next-token prediction and why a plausible response can still be wrong ([Large Language Models](https://www.youtube.com/watch?v=osKyvYJ3PRM), [LLM Deep Dive](https://www.youtube.com/watch?v=7xTGNNLPyMI))
3. [ ] Explain hallucinations, test model answers against known facts or inspectable sources, record corrections, and explain why the person using the output remains responsible for the final decision ([Hallucinations @ 01:20:44](https://www.youtube.com/watch?v=7xTGNNLPyMI&t=4844s), [Testing Known Answers @ 01:26:09](https://www.youtube.com/watch?v=7xTGNNLPyMI&t=5169s), [Human Responsibility @ 03:09:21](https://www.youtube.com/watch?v=7xTGNNLPyMI&t=11361s))
4. [ ] Compare integrated browser assistants using the same article or PDF in Edge and Chrome. Test summarization, explanation, page-based questions, and quizzes; inspect shared browser data and verify answers against the source ([Copilot in Microsoft Edge](https://support.microsoft.com/en-us/microsoft-copilot/getting-started-with-copilot-in-microsoft-edge), [Gemini in Chrome](https://support.google.com/chrome/answer/16283624?hl=en), [Gemini Source Links](https://support.google.com/gemini/answer/14143489?co=GENIE.Platform%3DDesktop&hl=en), [Lateral Reading](https://cor.inquirygroup.org/curriculum/collections/teaching-lateral-reading/))
5. [ ] Use Gemini for practical learning and productivity tasks involving text, files, images, model selection, temporary conversations, Canvas, Guided Learning, and Deep Research. Record which feature fits each task and why ([Gemini Practical Course](https://www.youtube.com/watch?v=-_FizlRlfYs))
6. [ ] Use ChatGPT Study Mode to conduct a guided learning session with prior-knowledge questions, explanations, learner attempts, feedback, and a mastery check. Compare guided study with ordinary direct-answer chat using the same learning goal and criteria ([Introducing Study Mode](https://www.youtube.com/watch?v=XDYilxy1dn8), [Study Mode Guide](https://help.openai.com/en/articles/11780217-study-mode), [Evaluation Best Practices](https://developers.openai.com/api/docs/guides/evaluation-best-practices))
7. [ ] Build a source-grounded Gemini Notebook containing trustworthy files, websites, and conversations. Organize a project, configure notebook memory and custom instructions, use cited chat, and verify important claims against their sources ([Gemini Notebook Integration](https://www.youtube.com/watch?v=Y-LTxr1bv9M), [Product Guide](https://support.google.com/gemininotebook/answer/16164461?hl=en))
8. [ ] Conduct the same focused research question with two deep-research tools. Review the research plans, open cited sources, and compare report scope, source selection and quality, citation traceability, and claims that fail source checks ([Gemini Practical Course](https://www.youtube.com/watch?v=-_FizlRlfYs), [Gemini Deep Research Guide](https://support.google.com/gemini/answer/15719111?hl=en), [ChatGPT Deep Research](https://www.youtube.com/watch?v=YkCDVn3_wiw), [ChatGPT Deep Research Guide](https://help.openai.com/en/articles/10500283-deep-research), [Lateral Reading](https://cor.inquirygroup.org/curriculum/collections/teaching-lateral-reading/), [Evaluation Best Practices](https://developers.openai.com/api/docs/guides/evaluation-best-practices))
9. [ ] Apply prompt-engineering principles to everyday tasks: define the goal, audience, context, constraints, examples, and output format; test prompts against several inputs and improve them using a quality rubric ([Prompt Engineering Guide](https://www.youtube.com/watch?v=uDIW34h8cmM), [OpenAI Prompt Engineering](https://developers.openai.com/api/docs/guides/prompt-engineering), [Evaluation Best Practices](https://developers.openai.com/api/docs/guides/evaluation-best-practices))
10. [ ] Build a small prompt-based application that summarizes, infers, transforms, or expands text. Inspect edge cases, require structured outputs, iterate on failures, and include human review before using the result ([Prompt Engineering for Developers](https://www.deeplearning.ai/short-courses/chatgpt-prompt-engineering-for-developers/), [OpenAI Prompt Engineering](https://developers.openai.com/api/docs/guides/prompt-engineering), [Structured Outputs](https://developers.openai.com/api/docs/guides/structured-outputs), [Evaluation Best Practices](https://developers.openai.com/api/docs/guides/evaluation-best-practices))
11. [ ] Apply context engineering by creating a reusable context pack containing goals, source links, examples, constraints, vocabulary, project conventions, and a definition of done. Run the same prompt with and without it and score both with the same rubric ([Context Engineering with Copilot](https://www.youtube.com/watch?v=0jEzUhU8bLc), [VS Code Context Engineering Guide](https://code.visualstudio.com/docs/agents/guides/context-engineering-guide), [VS Code Custom Instructions](https://code.visualstudio.com/docs/copilot/customization/custom-instructions), [Evaluation Best Practices](https://developers.openai.com/api/docs/guides/evaluation-best-practices))
12. [ ] Design a bounded AI loop with a goal, plan, action, observation, evaluation rubric, revision process, iteration limit, stop conditions, and human approval points. Test the loop with a writer, critic, and reviser workflow ([Agent-First Development](https://www.youtube.com/watch?v=uu4sf8z9n8c), [Agent Loop and Maximum Turns](https://openai.github.io/openai-agents-python/running_agents/#the-agent-loop), [Agent Orchestration](https://openai.github.io/openai-agents-python/multi_agent/))
13. [ ] Create a source-based content brief and transform it into an article, email, and social post for different audiences. Verify facts, preserve the intended voice, remove unsupported claims, and perform a human editorial review ([Gemini Practical Course](https://www.youtube.com/watch?v=-_FizlRlfYs), [Gemini Canvas](https://support.google.com/gemini/answer/16047321?hl=en), [Gemini Gems](https://support.google.com/gemini/answer/15236321?hl=en), [Gemini Source Links](https://support.google.com/gemini/answer/14143489?co=GENIE.Platform%3DDesktop&hl=en), [Evaluation Best Practices](https://developers.openai.com/api/docs/guides/evaluation-best-practices))
14. [ ] Generate image variations for a communication goal, inspect visible strengths and errors, compare the variations with an explicit rubric, and record the final human choice ([Image Creation Examples](https://www.youtube.com/watch?v=EUEsvyEMRzY), [Evaluation Best Practices](https://developers.openai.com/api/docs/guides/evaluation-best-practices))
15. [ ] Create a presentation from verified source material. Define the audience and objective, prepare a story outline, generate and simplify the slides, add accessible visuals and speaker notes, fact-check the content, and rehearse the result ([Gemini Notebook Integration](https://www.youtube.com/watch?v=Y-LTxr1bv9M), [Presentations with Microsoft 365 Copilot](https://www.youtube.com/watch?v=ioV4kREDrso), [Prepare a Presentation with Copilot](https://support.microsoft.com/en-us/office/prepare-your-presentation-with-copilot-for-microsoft-365-7f06429e-c0c2-4819-8119-b519ad599796), [Make PowerPoint Presentations Accessible](https://support.microsoft.com/en-us/accessibility/powerpoint/make-your-powerpoint-presentations-accessible-to-people-with-disabilities), [Rehearse with Speaker Coach](https://support.microsoft.com/en-us/powerpoint/rehearse-your-slide-show-with-speaker-coach))
16. [ ] Use GitHub Copilot in VS Code for code explanation, completion, design exploration, debugging, refactoring, tests, documentation, and review. Inspect suggested changes and run relevant checks before accepting them ([Getting Started with GitHub Copilot](https://www.youtube.com/watch?v=n0NlxUyA7FI), [Build with Agents in VS Code](https://code.visualstudio.com/docs/agents/overview), [VS Code AI Smart Actions](https://code.visualstudio.com/docs/editing/copilot-smart-actions), [Review and Revert Agent Changes](https://code.visualstudio.com/docs/agents/run/review-code-edits), [Coding-agent Task Practices](https://docs.github.com/en/copilot/using-github-copilot/using-copilot-coding-agent-to-work-on-tasks/best-practices-for-using-copilot-to-work-on-tasks))
17. [ ] Build a small feature with agent mode in VS Code. Provide a bounded issue and definition of done, review the proposed plan and commands, inspect each change, run tests, and evaluate the final diff ([Agent-First Development](https://www.youtube.com/watch?v=uu4sf8z9n8c), [Build an App with Agent Mode](https://www.youtube.com/watch?v=hmfldW7dmgw), [Coding-agent task practices](https://docs.github.com/en/copilot/using-github-copilot/using-copilot-coding-agent-to-work-on-tasks/best-practices-for-using-copilot-to-work-on-tasks), [Review Copilot output](https://docs.github.com/en/copilot/how-tos/copilot-on-github/use-copilot-agents/review-copilot-output))
18. [ ] Add persistent repository context containing architecture, conventions, build and test commands, safety rules, and completion criteria. Compare Copilot's work with and without these instructions using the same task and checks ([Context Engineering with Copilot](https://www.youtube.com/watch?v=0jEzUhU8bLc), [VS Code Custom Instructions](https://code.visualstudio.com/docs/copilot/customization/custom-instructions), [Evaluation Best Practices](https://developers.openai.com/api/docs/guides/evaluation-best-practices))
19. [ ] Use GitHub Copilot in Visual Studio for codebase questions, editing, refactoring, test generation, local-change review, and agent tasks. Compare the same bounded task and checks with VS Code for a C# or .NET project ([Agent Mode in Visual Studio](https://www.youtube.com/watch?v=7_duh0HoT9o), [Copilot Chat in Visual Studio](https://learn.microsoft.com/en-us/visualstudio/ide/visual-studio-github-copilot-chat?view=vs-2022), [Visual Studio Custom Agents](https://learn.microsoft.com/en-us/visualstudio/ide/copilot-specialized-agents?view=visualstudio), [Manage Chat and Git Context](https://learn.microsoft.com/en-us/visualstudio/ide/copilot-chat-context-references?view=vs-2022), [Build with Agents in VS Code](https://code.visualstudio.com/docs/agents/overview), [Evaluation Best Practices](https://developers.openai.com/api/docs/guides/evaluation-best-practices))
20. [ ] Explore how AI changes application development, including intelligent product features, smaller models, multimodal interfaces, tool use, and agentic systems. Create an AI opportunity map for an existing application with evaluation criteria, risks, and non-AI alternatives or fallbacks ([AI for Application Developers](https://www.youtube.com/watch?v=awztkr8n0AA), [NIST AI RMF Playbook](https://www.nist.gov/itl/ai-risk-management-framework/nist-ai-rmf-playbook), [Agent Framework Evaluation](https://learn.microsoft.com/en-us/agent-framework/agents/evaluation))
21. [ ] Produce an integrated portfolio project containing a source-grounded research brief, an educational artifact, an image or presentation, and a small AI-assisted application. Include the prompts, context, sources, checks, corrections, and human-controlled decisions
