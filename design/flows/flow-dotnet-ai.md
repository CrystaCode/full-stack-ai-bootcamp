## Overview
In this flow, we will explore how to integrate AI capabilities into .NET applications using the Microsoft Extensions AI library. This library provides a set of tools and APIs that make it easier to build intelligent applications with C#.

Following steps help you to master these topics:
  - Microsoft Extensions AI
  - Microsoft Agent Framework
  - Generative UI with AG-UI & A2UI
