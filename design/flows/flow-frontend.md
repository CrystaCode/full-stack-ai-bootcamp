## Overview
In this flow, we will explore the frontend foundation of web applications: HTML and CSS. You will learn semantic markup, styling with selectors and the box model, modern layout techniques with flexbox and grid, positioning, transitions, and responsive design. This flow covers the presentation layer only; interactivity and application logic are covered by the dedicated .NET flows that build on this foundation.

Following steps help you to master these topics:
  - HTML Semantics and Structure
  - CSS Selectors and the Box Model
  - Flexbox and Grid Layout
  - Responsive Web Design
